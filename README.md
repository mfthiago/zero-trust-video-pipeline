# Zero Trust video pipeline

A single file Node pipeline that turns a written script into a finished narrated video.

**Result:** a 48 second explainer on Zero Trust, 7 shots: https://youtu.be/EKNwxXxa2Q0

## What it does

For each scene in the script:

1. Narration is generated by a TTS model (Gemini TTS via Kie).
2. A shot is generated from a written prompt by a video model (Veo 3.1 via Kie).
3. FFmpeg trims the shot to the length of its narration and muxes them.

Then the scenes are concatenated into one mp4.

## Decisions worth reading the code for

* **Narration drives the edit.** Each shot is cut to its line, never looped. An earlier version looped an 8 second take under a longer line and visibly replayed its first second before every cut.
* **Self check before spending credits.** `check()` runs before every real run and rejects any scene whose narration would outrun the 8 second take (about 18 words at the measured 151 wpm of the voice).
* **Resumable per scene.** Finished clips and voice files are cached in `build/`, so a rejected take is regenerated alone by deleting its file, without paying for the others again.
* **Continuity is written, not hoped for.** Text to video has no memory between takes, so recurring characters carry the same description word for word in every prompt, and the intruder is always shot from behind.
* **No dependencies.** Node 18+ `fetch`, the standard library and FFmpeg.

## Run

```bash
node make-video.mjs --check              # validate the script, no credits spent
KIE_API_KEY=... node make-video.mjs      # generate, then writes zero-trust.mp4
```

Needs Node 18+ and `ffmpeg` on PATH. Model and voice can be overridden with `KIE_VIDEO_MODEL`, `KIE_VOICE_MODEL` and `KIE_VOICE`.
